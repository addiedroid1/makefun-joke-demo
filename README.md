A one-line joke about an AI coding agent fixing a live demo crash — by making the error page the homepage, so the app has loaded perfectly ever since. Written for make.fun's "The joke about the demo" bounty: the program writes exactly that one line to `entry.txt`, and an AI comedy judge compares it against the other entrants' jokes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

That writes the joke to `out/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to any local folder to see it; in the grading sandbox it defaults to `/output`).
